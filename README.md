# Clockback

Clockback is a phone-first web app that helps people with a drifting sleep schedule move their bedtime earlier in small steps. Many trackers depend on the user remembering to open them at the exact moment they are least likely to. Clockback is designed around that weakness: one-tap logging, a one-day "second chance" correction rule, and clear labels that separate tapped times from times entered later, so the data stays honest.

**Planned stack:** Next.js, React, Tailwind CSS, PostgreSQL (plain JavaScript first, TypeScript later).

## Status

Early stage. The project is planned and the Next.js app is set up with a couple of placeholder pages. There are no features, no database, no tests, and no deployment yet.

The full plan is in [`docs/Clockback_spec.md`](docs/Clockback_spec.md), and current progress is tracked in [`docs/PROGRESS.md`](docs/PROGRESS.md).

## Running locally

Requires Node.js.

```bash
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000) in your browser.
